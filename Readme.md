# Level 1 Practice Programs

## 📌 Overview
This collection of beginner-friendly programming exercises is designed to build a strong foundation in logical thinking, decision-making, loops, and basic arithmetic operations. These exercises will help me strengthen my understanding of **conditions, loops, functions, and user inputs** in programming.

---

## 🚀 What I have Learned

### ✅ **Basic Conditions & Comparisons**
- Understanding how to check divisibility (e.g., is a number divisible by 5?).
- Comparing numbers to find the smallest or largest.
- Checking whether a number is **positive, negative, or zero**.
- Determining if a person is eligible to vote based on their age.
- Identifying a **Spring Season** based on month and date.

### 🔄 **Loops & Iterations**
- Using **while loops** for countdowns (rocket launch sequence).
- Using **for loops** for countdowns and iterations.
- Finding the sum of **n natural numbers** using loops.
- Comparing computed results with mathematical formulas.
- Printing **odd and even numbers** up to a given number.
- Finding the **factorial** of a number using both `while` and `for` loops.

### 🔢 **Mathematical Computations**
- Checking if a number is a **natural number**.
- Summing numbers until I enter **0**.
- Summing numbers until I enter **0 or a negative number** (with `break` statement).
- Finding **multiplication tables** for a given number (from 6 to 9).

### 💰 **Decision Making in Real-Life Scenarios**
- Calculating employee **bonus** based on years of service.
- Using conditions to determine when to exit a loop.

---

## 🏆 Skills I have been Developed
- **Problem-Solving Mindset**: Break down complex problems into smaller logical steps.
- **Conditional Statements**: Master `if`, `else`, and `elif` conditions.
- **Loop Mastery**: Learn `for` and `while` loops for automation.
- **User Input Handling**: Take user inputs dynamically and process them effectively.
- **Mathematical Computations**: Work with mathematical formulas in programming.
- **Real-World Application**: Apply programming concepts to real-life scenarios like voting, salary bonuses, and seasonal checks.
